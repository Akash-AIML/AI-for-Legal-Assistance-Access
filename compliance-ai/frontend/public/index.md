# LegalLens AI

LegalLens AI is an Enterprise Compliance & Operations Assistant that uses a LangGraph-driven Evidence Decision Engine to actively resolve outdated, conflicting, or unauthorized information.

## Key Features
- **Structure-Aware Chunking:** Parses logical document boundaries.
- **RBAC Meta-filtering:** Database-level role-based access control.
- **Pre-LLM Precedence:** Resolves version and date conflicts before they hit the LLM.
- **Hybrid RRF Search:** Combines dense semantic and sparse BM25 search.
- **LangGraph State Machine:** Bounds LLM responses to prevent hallucination.
