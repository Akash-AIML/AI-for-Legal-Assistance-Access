# Purpose
Defines access control and authentication requirements aligned to ISO 27001 Annex A.

# Password Requirements
Per ISO 27001, passwords must be at least 12 characters and include upper, lower, and numeric characters.

# Multi-factor Authentication
MFA is mandatory for all administrative and remote access.

# A.9 Access Control
Access is granted on a least-privilege basis and reviewed quarterly.
